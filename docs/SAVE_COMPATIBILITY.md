# 新旧猎场存档与菜单续接

游戏仍为单文件 `index.html`，没有单独的core目录。启动、设置进度和手动继续共用同一存档选择器，避免三处接线再次分叉。

## 持久化字段与优先级

localStorage键保持 `wolf_sheep_v26_memory`。不重命名或清空旧字段。

1. 有效 `candidateLast`：`id`必须是HUNTS自有的稳定字符串ID，`difficulty`必须为easy/hard。设置显示教程/甜品原型、名称（教程含T编号，原型含d23/d26）、难度。恢复新猎场时使用固定规则，清除内存中上一个自由模式种子。
2. 有效 `lastPlayedRun`：旧20关索引、难度、标准/自由模式及已支持ruleset均需有效。
3. 有效 `activeV25`：上项不存在或无效时才回退。最后保留原有启动快照作为内存兜底。
4. 都无效：显示“暂无”，手动继续不创造进度；页面默认打开T1。

无效的新字段不会盖住有效旧字段；无效记录不会因为菜单展示而被删除。旧版支持的迁移行为保留：较早ruleset进入兼容首关，设置明确注明；当前v32.1、v32.0、v31.3旧20关存档按原索引恢复。旧自由模式保留保存的种子和难度。

## 什么时候更换“上次关卡”

只有点击“开始猎捕”才更新最近玩过的关卡。选关、返回第一关、重开或恢复到预览均不会单独覆盖它。

- 开始新猎场：写 `candidateLast`，保留 `lastPlayedRun / activeV25` 和旧成绩。
- 只预览旧关：仍优先续接之前真正开始的新猎场。
- 开始旧关：移除 `candidateLast`，沿用原有旧关记录写入，之后自动/手动续接旧关。
- 再开始新猎场：重新写入新ID与难度；新旧分数仍分别保存。
- 新猎场本身是固定布局，不继承选关面板上旧自由模式标签或种子。

“下次自动接续关卡”只控制页面启动。关闭它后仍可从设置手动继续。恢复的是所选关卡的重新开局预览，不是中途回合快照；本次未新增回合存档语义。
